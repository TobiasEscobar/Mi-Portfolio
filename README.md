## 💡 Sobre el Proyecto

El objetivo principal de esta aplicación es centralizar mi identidad profesional en una plataforma interactiva y performante. No es solo una muestra de información, sino una demostración práctica de mis capacidades en el desarrollo Frontend moderno.

### 🛠 Tecnologías y Herramientas

El proyecto fue construido utilizando una arquitectura robusta y escalable:

| Categoría | Tecnologías |
|-----------|-------------|
| **Framework** | ![Angular](https://img.shields.io/badge/Angular-DD0031?style=flat-square&logo=angular&logoColor=white) **Angular 17+** (Standalone Components) |
| **Estilos** | ![Bootstrap](https://img.shields.io/badge/Bootstrap-563D7C?style=flat-square&logo=bootstrap&logoColor=white) ![SASS](https://img.shields.io/badge/SASS-hotpink?style=flat-square&logo=SASS&logoColor=white) |
| **Lenguaje** | ![TypeScript](https://img.shields.io/badge/TypeScript-007ACC?style=flat-square&logo=typescript&logoColor=white) |
| **Funcionalidades** | **EmailJS** (Contacto), **SweetAlert2** (Notificaciones) |
| **Deploy** | **Vercel** |

## ✨ Características Destacadas

- **Diseño Responsivo:** Adaptabilidad total a móviles, tablets y escritorio.
- **Formulario de Contacto Real:** Integración con servicio de correo sin backend dedicado.
- **Navegación SPA:** Experiencia de usuario fluida sin recargas de página.
- **Clean Code:** Estructura modular basada en componentes reutilizables.
